# تطبيق استعلام الأصناف والأسعار

مشروع Flutter يعمل محلياً على الهاتف. قاعدة البيانات SQLite داخل الجهاز، لذلك لا يحتاج البحث أو الإضافة أو التعديل إلى إنترنت.

## الوظائف الموجودة في هذه النسخة

- بحث بالاسم أو رقم الصنف أو الباركود، وعرض سعر الشراء وسعر البيع والوحدة والكمية.
- مسح باركود بالكاميرا عبر mobile_scanner.
- إضافة الأصناف وتعديلها وحذفها.
- قاعدة بيانات SQLite محلية مع فهارس على الاسم والكود والباركود.
- استيراد ملفات XLSX وCSV، مع شاشة مطابقة الأعمدة ومعاينة أول خمسة صفوف.
- توليد EAN-13 داخلي تلقائياً للأصناف التي لا تحتوي على باركود، مع عرض/طباعة Code 128 وEAN-13 وEAN-8 وQR عند صلاحية البيانات للصيغة.
- إنشاء ملصقات PDF وفتح نافذة الطباعة من النظام.
- تصدير واستعادة نسخة احتياطية من قاعدة البيانات.
- تغيير رمز العملة، والافتراضي الريال اليمني (ر.ي).

## أمور تحتاج استكمالاً واختباراً على جهازك

- الاتصال المباشر بطابعة حرارية Bluetooth غير مفعّل في هذه النسخة. الطباعة المتاحة هي PDF عبر نافذة الطباعة في Android. إضافة Bluetooth تعتمد على موديل الطابعة ونوع اتصالها، ويجب اختبارها فعلياً.
- ملف PDF الحالي يعرض الباركود ورقم الصنف والسعر، دون اسم الصنف العربي. طباعة اسم الصنف العربي داخل الملصق تحتاج تضمين خط عربي مرخّص داخل المشروع.
- استيراد XLSX يعتمد على أول ورقة عمل، ويعتبر الصف الأول عناوين الأعمدة.
- هدف سرعة البحث مع 50,000 صنف يجب قياسه على الهاتف وقاعدة بيانات فعلية. الفهارس موجودة، لكن البحث الجزئي الذي يبدأ بعلامة % ليس مضموناً أن يستخدم الفهرس.
- لم يتم تشغيل Flutter Analyzer أو بناء APK في بيئة الإنشاء الحالية لعدم توفر Flutter SDK هنا. يجب أن ينجح البناء السحابي أولاً قبل اعتبار النسخة مجرّبة.

## رفع المشروع إلى GitHub من الهاتف

1. فك ضغط ملف ZIP على هاتفك.
2. افتح https://github.com وسجّل الدخول أو أنشئ حساباً.
3. اضغط + ثم New repository.
4. اكتب اسماً مثل `price-inquiry-app`، واختر Private أو Public، ثم Create repository.
5. افتح المستودع واضغط Add file ثم Upload files.
6. ارفع محتويات المجلد المفكوك، وليس ملف ZIP وحده. يجب أن يظهر `pubspec.yaml` و`codemagic.yaml` في جذر المستودع، ومجلد `lib` ومجلد `codemagic_assets` بجوارهما.
7. اضغط Commit changes.

إذا لم يسمح متصفح الهاتف برفع المجلدات المتداخلة، استخدم عرض سطح المكتب في المتصفح لرفع الملفات والمجلدات مع المحافظة على نفس ترتيبها.

## إنشاء APK عبر Codemagic

1. افتح https://codemagic.io وسجّل الدخول باستخدام GitHub.
2. اختر Add application ثم اربط مستودع `price-inquiry-app`.
3. اختر Flutter إن ظهر اختيار نوع المشروع. هذا المستودع يحتوي على `codemagic.yaml`.
4. افتح إعدادات التطبيق وتأكد من اختيار سير العمل `android-apk`.
5. ابدأ البناء Build.
6. انتظر اكتمال سجل البناء. عند النجاح افتح Artifacts ونزّل `app-release.apk`.
7. انقل APK إلى الهاتف وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

### التنبيه بشأن الخطة المجانية

ملف `codemagic.yaml` يختار `mac_mini_m2` لأن الخطة الفردية المجانية في Codemagic تتضمن حالياً 500 دقيقة شهرياً على أجهزة macOS M2. بناء Android على Linux لا يدخل ضمن الدقائق المجانية. راجع صفحة التسعير قبل بدء البناء، ولا تفعّل الفوترة أو الاستخدام المدفوع. قد تتغير الشروط والأسعار.

## تنبيه حول البيانات

البيانات تُحفظ محلياً على الجهاز الذي ثُبّت عليه التطبيق. لا توجد مزامنة تلقائية بين عدة هواتف. احتفظ بنسخة DB احتياطية قبل إعادة تثبيت التطبيق أو استعادة نسخة.
